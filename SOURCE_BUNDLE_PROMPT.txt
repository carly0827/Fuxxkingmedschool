이 대화에서는 업로드한 코드와 지시서를 기준으로만 작업해줘.

입력:
1) 파일명 끝이 줄.pdf 인 파일
2) 파일명 끝이 야붙.pdf 또는 야붙(n).pdf 인 파일
3) 전사문 텍스트

해야 할 일:
- 줄 파일의 기존 필기 내용은 절대 손상하지 말 것
- 야붙 파일의 1페이지는 맨 앞에 추가할 것
- 야붙에만 있는 중간 문제 페이지와 마지막 모아보기 페이지를 원래 위치에 삽입할 것
- 중간병합본부터 글씨가 깨지지 않게 원본 PDF 페이지 자체를 사용해 병합할 것
- 전사문은 1순위 지정 초록색(#007355 필기색, #A5C891 형광펜색), 2순위 전사문 페이지 수(줄 기준으로 해석하되 줄+야붙 병합 시 앞에 추가된 야붙 1페이지와 문제만 있는 페이지는 제외), 3순위 페이지 제목/부제목/핵심 bullet/영문 의학용어 정규화를 사용해 페이지와 매칭할 것
- 교수 설명이 한국어이고 슬라이드가 영어여도 핵심 단어를 영문 의학용어 canonical form으로 바꿔 비교할 것
- 전사문이 길면 continuation 페이지를 무제한 추가해서 절대 잘리지 않게 할 것
- 전사문 누락 검토, 페이지 계획, 줄야붙 병합 검증 파일도 함께 만들 것
- 최종 파일명은 원래 줄 파일명을 기준으로 줄 → 최종본으로 바꿀 것

먼저 업로드된 `CHATGPT_학습용_최종본_워크플로우_지시서.md`를 읽고, 그 다음 `code/` 폴더의 파이썬 파일들을 참고해서 같은 워크플로우로 진행해줘.


추가 규칙:
- 전체 전사문 요약 정리본은 강의록 원본을 시험용 표 정리본으로 압축한 것처럼 보이도록, 큰 섹션 제목 아래에 슬라이드별 표 블록을 세로로 배치해 읽기 쉽게 만든다.
- 하단 오른쪽 전사문 옆 요약은 시간/전사 페이지를 쓰지 말고 `항목 | 정리` 형식의 간결한 표만 넣는다.
- 구어체를 그대로 옮기지 말고 개념/대상/특징 중심으로 정리한다.
- 파일 다운로드 문제가 생기지 않게 pycache는 포함하지 말고, 번들 내부 파일명은 ASCII로 유지한다.

- 전체 전사문 요약 정리표는 DOCX를 먼저 만들고, 그 DOCX를 PDF로 변환할 것
- 변환이 실패하면 이미지 기반 PDF를 보조적으로 만들되 DOCX는 반드시 함께 남길 것
- 최종 결과를 사용자에게 줄 때는 직접 PDF보다 `*_safe_download.zip`을 우선 제공할 것
- 가능하면 `*_safe_full_archive.zip`도 같이 제공할 것

- 사용자에게 링크를 주기 직전에 `*_delivery_link_check.json/txt`를 보고, passed=true인 direct safe copy만 직접 링크로 제시할 것
- 원본 한글/공백 파일명 링크를 손으로 적지 말고, 검증된 ASCII direct safe copy 링크를 우선 사용할 것
- direct safe copy 검증이 실패하면 최종 PDF 직접 링크 대신 `*_safe_download.zip`만 먼저 줄 것
